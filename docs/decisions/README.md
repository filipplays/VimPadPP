# Architectural decisions

- [Neovim sessions belong to documents](neovim-document-sessions.md)

Add a decision record when a consequential choice needs a durable explanation
of its context and tradeoffs. Routine implementation choices do not need one.
Create records only when authorized to change project files.

Use a short, descriptive filename and include:

- Status and date.
- Context and the problem being addressed.
- The decision and alternatives considered.
- Consequences, tradeoffs, and any unresolved questions.
- Links to relevant code, documentation, or a superseding decision.

Record verified rationale and distinguish it from assumptions. Do not invent
historical decisions. When a decision changes, preserve the original record and
link it to the new one rather than rewriting its history.
